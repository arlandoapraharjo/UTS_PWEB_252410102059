# 5 Malam Haur Haur

Aplikasi web pengelolaan untuk **Night Technician** yang memantau dan mengelola unit animatronik bertema *Five Nights at Freddy's*. Proyek ini dibangun untuk memenuhi ketentuan **UTS Pemrograman Web 2026** menggunakan **Laravel murni** tanpa database maupun template starter kit.
